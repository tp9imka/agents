# Testing - Go

Rules in `CONSTITUTION.md` articles II and III.

## Workflow

1. Name the packages and types the change touches, in the task.
2. List the tests as table cases with behaviour names: `returns ErrEmptyCart when cart is empty`.
3. Per case: add the row, run `go test -race ./internal/orders/... -run TestPlaceOrder`, see it fail for the right reason, implement the minimum, run the package, refactor green.
4. Structural commits separate from behavioural ones.
5. Before done: `make check`; every file touched reads 100%.

## Test types

| Level | Tool | Location |
|---|---|---|
| unit (domain, use cases) | `testing` + `testify/require`, table-driven | next to the code, `_test.go` |
| adapter | httptest for handlers; sqlc against testcontainers Postgres | `adapters/*/…_test.go`, `integration/` |
| contract | golden JSON for HTTP responses (`goldie`) | `adapters/http/testdata/` |
| integration | testcontainers, `-tags integration` | `integration/` |

Fakes for own ports live in `internal/<feature>/app/apptest` (hand-written,
small). Mocks only for third-party clients, generated by `make gen` (mockery).

## Coverage gate

`.testcoverage.yml`:

```yaml
profile: coverage.out
threshold: { file: 100, package: 100, total: 100 }
exclude:
  paths:
    - ^cmd/
    - ^internal/app/app\.go$          # composition root, covered by the smoke test in integration/
    - \.sql\.go$
    - _mock\.go$
```

`make check` runs `go test -race -covermode=atomic -coverprofile=coverage.out ./...`
then `go-test-coverage --config .testcoverage.yml`, which prints uncovered
lines per file. Go has no line pragma: an unreachable branch is removed or the
I/O behind it moves behind a port with a fake. Never lower the thresholds; add
an `exclude` path only for generated code.

## Mutation

`gremlins unleash --tags="" ./internal/...` in `nightly.yml`, `--threshold-efficacy 80`.

## Rules

- `clock.Clock` and `io.Reader` for randomness are injected; `time.Now()` and `rand.` in use cases fail `forbidigo`.
- Failure path first: every returned error has a test case that triggers it.
- `t.Parallel()` on every test; shared state is a bug.
- No tests for constants, no assertion-free tests, no `t.Skip` without a linked task.
- Golden files are updated with `-update` only when the change to the contract is intended and reviewed.
